# 🍕 Pizza Sales Performance Report

## 📌 Project Overview

The **Pizza Sales Performance Report** is an interactive **Power BI dashboard** designed to analyze and visualize pizza sales data. The project provides meaningful insights into revenue, orders, sales trends, customer preferences, and product performance.

The dashboard helps identify key business trends and supports data-driven decision-making to improve sales performance and profitability.

## 🎯 Objectives

* Analyze overall pizza sales performance
* Track total revenue and total orders
* Identify top-selling pizza products
* Analyze sales by pizza category and size
* Identify peak sales days and months
* Understand customer ordering patterns
* Provide actionable business insights through visualizations

## 📊 Key Metrics

* **Total Revenue**
* **Total Orders**
* **Total Pizzas Sold**
* **Average Order Value**
* **Average Pizzas per Order**
* **Daily & Monthly Sales Trends**
* **Top & Bottom Performing Pizzas**

## 🔍 Key Analysis

The dashboard provides analysis based on:

* Pizza Category
* Pizza Size
* Pizza Type
* Order Date
* Day of the Week
* Month
* Revenue
* Quantity Sold
* Number of Orders

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **SQL** – Data querying and analysis
* **Excel/CSV** – Data storage and preparation
* **DAX** – Calculated measures and KPIs

## 📈 Dashboard Insights

The report helps answer questions such as:

* Which pizza generates the highest revenue?
* Which pizza category has the highest sales?
* Which pizza size is most popular?
* What are the busiest days and months?
* Which pizzas are underperforming?
* How does revenue change over time?
* What are the overall sales trends?
